# 연출 실험실 (tools/fxlab)

게임 엔진 없이 WebGL(PixiJS)로 마법 연출을 그리면 얼마나 달라지는지 보는 시험 페이지. **게임 코드는 바꾸지 않는다.**

## 여는 법
`meteor.html`을 Chrome이나 Edge에서 연다(더블클릭). 인터넷 없이 열린다.

- **방식**: 현재 (DOM) = 게임의 `js/spellfx.js` 메테오를 그대로 부른 것 / PixiJS (WebGL) = 새로 만든 메테오
- **대상**: 한 장 · 세 장 (세 장이면 게임처럼 80ms 간격으로 떨어진다)
- **연출**: 가볍게 · 화려하게 (게임 설정 '연출'과 같은 뜻. 기본은 가볍게)
- **번갈아 보기**: 두 방식을 2.6초마다 번갈아 보여 준다
- **연속 5번**: 부하 시험. 아래 숫자(평균 fps · 가장 긴 프레임 · 조각 수)로 무게를 본다
- 적 카드를 누르면 그 카드에 떨어진다. 스페이스 = 발동, 1 / 2 = 방식 바꾸기

## 파일
| 파일 | 내용 |
|---|---|
| `meteor.html` | 비교 판. 게임의 `js/feel.js` · `js/spellfx.js` · `js/impact.js` · `css/spellfx.css` · `css/impact.css`를 그대로 읽고, `js/game.js`에 있는 것(G · uidEl · shakeEl …)은 최소한의 대역으로 채운다 |
| `pixi-meteor.js` | PixiJS 메테오(`PixiFX.meteor`). 그림 파일 없이 캔버스로 만든 질감만 쓴다 |
| `vendor/` | PixiJS 8.22.0 · pixi-filters 6.1.5 (둘 다 MIT, 라이선스 파일 함께 있음) |

## PixiJS 메테오에서 달라진 것
- 예고: 대상 발밑 룬 고리가 차오르고(스타일 가이드 2.9 룬 고리 문법), 하늘 들어오는 자리가 달아오른다
- 낙하: 불타는 바위(돌며 용암 금) + 불꼬리 · 연기 · 튀는 불티. 빛이 겹칠수록 밝아진다(가산 합성)
- 맞는 순간: 히트 스톱(55ms) · 빛살 · 땅 고리 · 불덩이 · 바위 파편(땅에서 튐) · 불꽃 줄기 · 연기 기둥 · 오래 남는 그을음과 용암 금
- 화려하게만: 빛 번짐(AdvancedBloom) + 충격파 일그러짐(Shockwave)
- 카드 반응(흔들림 · 번쩍 · 고리)과 소리는 게임 것(`js/impact.js` · `js/feel.js`)을 그대로 쓴다
- 맞는 때는 실제 시계를 따른다(느린 기기에서도 숫자가 뜨는 때와 어긋나지 않음)

## 게임에 넣는다면
카드 · UI는 DOM 그대로 두고 `#fx-layer` 위에 PixiJS 캔버스 한 장을 덮는다. `js/spellfx.js`의 `HIT.<모양>.run`을 하나씩 `PixiFX`로 옮기고,
`at()`이 돌려주는 ms 약속만 지키면 `js/game.js`는 고칠 것이 없다. 연출용이라 `Math.random`을 써도 온라인 대전에 영향이 없다.
안드로이드 앱(WebView)도 그대로 따라온다.
한계: 캔버스가 카드 위에 덮이는 방식이라 충격파 일그러짐은 연출(불 · 연기)에만 걸리고 아래 카드 그림은 휘지 않는다.
