# ETHERION 번역 지침 (English · 日本語 · 简体中文)

게임 화면 글과 카드 글을 옮길 때 따른다. 소설 · 연대기 · 카일란 · 순례 대사는 옮기지 않는다(한국어로만).
구조와 파일은 `AGENTS.md` "다국어", 코드는 `js/i18n.js`.

## 1. 용어집이 먼저
- `js/i18n/glossary.js` — `KW`(카드 능력 · 키워드)와 `TERM`(게임 낱말 · 깃발 · 진영 · 고유명사). 값은 `[English, 日本語, 简体中文]`.
- 이 표에 있는 낱말은 **반드시 표의 말 그대로** 쓴다(문장 속에서도). 영어는 문장 속이면 소문자로 써도 된다(Ether, Coin, Life는 대문자 유지).
- 카드 글의 `[키워드 N]`은 괄호 안 이름을 KW 표의 그 말 이름으로 바꾸고 숫자 · 기호는 그대로: `[사격 1]` → `[Shot 1]` · `[射撃 1]` · `[射击 1]`. 괄호 수는 원문과 같게.
- 표에 없는 고유명사(지명 · 인명)는 로마자로 소리대로(영어), 그 소리의 가타카나(일본어), 음역 한자(중국어). 같은 낱말은 같은 일감 안에서 늘 같게.

## 2. 꼭 지킬 형식 (tools/i18n/validate.js가 본다)
- 숫자: 원문의 숫자(아라비아 숫자)를 **하나도 빼거나 더하지 않는다**. 한자 숫자 · 영어 낱말 숫자로 바꾸지 않는다. 원문에 숫자가 없는 곳(예: "두 번")은 숫자를 새로 쓰지 말고 낱말로(twice · 2回 대신 二度 X → "twice" / "二度" 는 괜찮다 — 아라비아 숫자만 안 됨).
- `{0}` `{1}` …: 화면이 숫자 · 이름을 끼우는 자리. 모두 남기고, 자리(순서)는 그 말의 어순에 맞게 옮겨도 된다.
- 코인 표기 `+1C×2` · `−1C` · `+2C` 는 그대로(마이너스는 `−` U+2212 그대로). 기호 `⚔ ⛨ ♥ ● → ◎ ▲ ▼ 🔒` 그대로.
- 한글이 남으면 안 된다. 원문 앞뒤의 `·` `—` `:` 같은 꾸밈 기호는 남긴다.
- 핸드 짧은 문구(`b`): `|`는 줄 나눔(수 그대로), `{…}`는 대상 칩(수와 순서 그대로). 칩 안은 아주 짧게:
  `{적 유닛 1}` → `{Foe 1}` / `{敵1体}` / `{敌方1个}` · `{적 앞 2개}` → `{Foe front 2}` / `{敵前2体}` / `{敌前2个}` · `{아군 앞 2개}` → `{Ally front 2}` / `{味方前2体}` / `{友方前2个}` · `{적 전체}` → `{All foes}` / `{敵全体}` / `{敌方全体}` · `{나}` → `{Self}` / `{自分}` / `{自身}` · `{대가}` → `{Cost}` / `{代償}` / `{代价}`.

## 4. 말투
- **English**: 짧고 또렷하게. 단추 · 제목은 Title Case 짧게(“Ready”, “Deck Workshop”), 설명 · 알림은 보통 문장. 카드 이름 Title Case, 될수록 22자 안. 카드 규칙 글은 MTG/Hearthstone 같은 명령형 · 현재형("Deal 2 damage to …", "Allied front 2 units: ATK +4.").
- **日本語**: 画面の案内・通知は です/ます 体。ボタン・見出しは体言止めで短く。カード名は10字前後まで。カードの効果文は 常体・体言止め(「敵ユニット1体の体力−2。」)。カタカナ語は一般的なゲーム用語に合わせる。
- **简体中文**: 简洁的游戏用语。按钮・标题要短。卡牌名尽量 8 字以内。效果文用规则式短句(“对敌方单位1个造成体力−2。”)。只用简体字。
- 서사(`f`, 카드 분위기 글): 원문처럼 담담하고 짧게, 원문보다 길지 않게(카드 글 상자가 작다). 뜻을 지어내지 않는다.
- 종류(`k`, 유닛의 종족 · 몸): 짧은 명사(“Ember Mule” / “灰ラバ” / “灰骡”).
- 화면 글 조각: 열쇠 하나는 화면의 글 마디 하나다. HTML 태그에서 끊긴 반쪽 문장일 수 있다 — 그 조각만 보고도 자연스럽게, 앞뒤에 이어질 것을 생각해 옮긴다. "을(를)" "이(가)" 같은 조사 표기는 버린다.
- 개수 낱말 "장"(카드) · "기"(유닛) · "개": English "cards/units"(1이어도 복수 괜찮음, 또는 ×N), 日本語 "枚/体/個", 中文 "张/个/个".
