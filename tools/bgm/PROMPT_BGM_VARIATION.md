# ETHERION 배경음 2차 — 변주 · 강약 더하기 (작업 지시서)

> 음악 담당 AI(안티그래비티)에게 그대로 준다. 1차 지시서는 `tools/bgm/PROMPT_BGM.md`, 1차 결과 설명은 `audio/bgm/NOTES_v3.43.2.md`.

---

## 0. 한 줄
1차 15곡은 **서정적인 결은 좋다.** 그런데 곡 처음부터 끝까지 결이 비슷해 **변주가 없다.**
같은 곡 안에서 **때로는 피아노 홀로, 때로는 선율 하나만, 때로는 웅장하게, 클라이맥스는 화려하게** 바뀌도록 15곡을 다시 만든다.
선율 · 조 · 박자 · 빠르기 · 곡의 성격은 1차의 것을 바탕으로 해도 되고, 더 좋게 고쳐도 된다.

## 1. 바뀐 편성 규칙 (1차와 다른 점)
- **피아노를 쓴다.** 콘서트 그랜드, 부드럽게(댐퍼 페달, 여린 타건, 홀 잔향). 장난감 같은 "땡땡" 소리 · 짧게 끊는 스타카토 반주는 안 된다.
- **하프를 쓴다.** 클라이맥스 들어가기 전 글리산도, 화려한 부분의 펼침화음에만.
- **팀파니는 클라이맥스에만**: 롤(크레셴도)과 총주 첫 박 한 번. 박자를 계속 치는 북 반주는 안 된다.
- 여전히 쓰지 않는 것: 오르골 · 첼레스타 · 마림바 · 실로폰 · 기타 · 신시사이저 · 전자 드럼 · 계속 치는 타악기. 가사 없음.

## 2. 곡 안의 "결" 여섯 가지 — 이것을 섞어 변주한다
| 결 | 무엇 | 크기(대략) |
|---|---|---|
| ① 피아노 홀로 | 피아노만. 주제를 조용히, 왼손 펼침화음 + 오른손 선율 | 아주 여림 (−26 ~ −22 dBFS RMS) |
| ② 단일 선율 | 독주 악기 하나(첼로 · 바이올린 · 오보에 · 플루트 · 호른 중)가 노래, 반주는 없거나 저음 한 음 · 피아노 몇 음 | 여림 |
| ③ 실내악 | 독주 + 피아노, 또는 현악 4~5명 | 여림 ~ 보통 |
| ④ 서정 합주 | 현악 합주가 노래, 목관 대선율 (1차 곡의 결) | 보통 |
| ⑤ 웅장한 총주 | 현 옥타브 · 호른 합주 선율 · 저음 박동 · 가사 없는 합창 | 셈 |
| ⑥ 화려한 클라이맥스 | ⑤ + 하프 글리산도 · 피아노 빠른 펼침화음 · 바이올린 높은 대선율(장식음 · 빠른 음형) · 트레몰로 현 · 팀파니 롤, 반음 또는 온음 올려 조바꿈해도 좋음 | 가장 셈 (−13 ~ −11 dBFS RMS) |

**규칙**
- 곡마다 **결을 4가지 이상** 쓴다. 그중 **조용한 결(① 또는 ②) 하나 이상**, **⑤ 또는 ⑥ 하나 이상**.
- 같은 주제를 결만 바꿔 되풀이하는 것이 변주다: 피아노로 처음 들려준 주제가 나중에 총주로 크게 돌아오면 좋다. 장식 · 리듬 · 화성도 돌아올 때마다 조금씩 바꾼다.
- 가장 여린 곳과 가장 센 곳의 차이 **약 12~15 dB**. 진짜로 작아졌다가 진짜로 커져야 한다(크기를 고르게 누르는 압축 금지, 봉우리 리미터만).
- 결이 바뀔 때는 갑자기 뚝 끊지 말고 크레셴도 · 디미누엔도 · 리타르단도 · 한 박 쉼 · 하프 글리산도 같은 다리로 잇는다.
- 클라이맥스는 곡 길이의 **60~80% 지점**에 한 번. 그 뒤는 가라앉아 조용히 끝나고 **처음으로 이음새 없이** 이어진다(곡 처음과 끝의 결 · 크기가 맞아야 반복이 자연스럽다).

## 3. 곡마다 흐름 (제안 — 더 좋은 흐름이면 바꿔도 된다)
**타이틀 `title`** (1:20~1:40, 반복) — ① 피아노가 주제 → ② 첼로 독주 + 피아노 → ⑤ 총주가 부풀어 → ⑥ 짧고 화려한 정점 → ① 피아노로 돌아와 처음으로.

**대전 5곡** (각 2:30~3:30) — 판을 두는 동안 깔리므로 조용한 결의 비중을 넉넉히(절반 정도).
- `bgm_reminiscence` 빛바랜 기억: ① 피아노 → ② 플루트 독주 → ④ 현 합주 → ③ 바이올린 + 피아노 → ⑥ → ① 피아노 마무리.
- `bgm_long_ago` 먼 옛날의 오후(밝음): ③ 오보에 + 피아노 → ④ → ② 클라리넷 홀로 → ⑤ → ⑥ 짧게 → ③.
- `bgm_last_oath` 최후의 서약(비장): ② 첼로 홀로 → ① 피아노 → ③ 바이올린 + 피아노 → ⑤ → ② 바이올린 홀로 → ⑥(조바꿈) → ② 첼로 홀로.
- `bgm_ashen_banner` 잿빛 깃발 아래(행진): 저음 현 박동만 → ② 호른 독주 → ④ → ① 피아노가 행진 주제를 여리게 → ⑤ → ⑥(팀파니 롤) → 박동만 남아 사라짐.
- `bgm_fallen_star` 별이 진 자리(서정): ② 바이올린 홀로 → ① 피아노 → ③ 첼로 + 피아노 → ④ → ⑥ → ① 피아노 + ② 바이올린 이중주.

**깃발 9곡** (각 2:00~3:00, 1차에서 짧았던 `flag_G3` 1:11 · `flag_A3` 1:07도 2분 이상으로) — 깃발마다 색 악기(1차 지시서 표)를 **② 단일 선율 결의 주인공**으로 쓴다(고블린 클라리넷, 드워프 바순 · 첼로, 노움 플루트, 오크 잉글리시 호른 빛 오보에, 트롤 오보에, 인어 플루트, 마족 클라리넷 · 첼로, 천족 호른 · 플루트, 하이엘프 플루트).
- 흐름 틀: ① 또는 ② 로 열기 → ④ → ② 색 악기 홀로 → ⑤ → ⑥ → ① 또는 ③ 으로 닫기.
- 성격에 맞게: 고블린 · 노움은 ⑥에서 경쾌하고 반짝이게, 드워프 · 오크는 ⑤를 묵직하게, 트롤 · 인어는 ① 피아노 비중을 크게(물 · 숲의 고요), 마족은 ① 피아노를 어둡게(낮은 음역), 천족은 ⑥에 합창을 크게, 하이엘프는 하프를 많이.

## 4. 소리 크기 · 파일 (1차와 같음, 바뀐 곳만 굵게)
- 곡 전체 RMS 약 −17 dBFS(통합 −15 LUFS 안팎)로 15곡을 비슷하게. **곡 안의 차이는 위 12~15 dB**, 봉우리 −1 dBFS 이하.
- 게임이 틀 때 저역 +2.8dB · 고역 −2.8dB · 짧은 잔향 · 가벼운 압축을 한 번 더 건다(`js/bgm.js` `bus`). 저음 · 잔향을 과하게 넣지 말 것.
- 44.1 kHz 스테레오, `.ogg`(Vorbis q4) · `.mp3`(128k). 파일 이름은 1차와 같다.
- **`audio/bgm/new/`** 에 넣는다(지금 곡을 덮어쓰지 않음). 곡마다 흐름(몇 초에 어떤 결인지)을 `audio/bgm/new/NOTES.md`에.
- 소리 엔진(`tools/bgm/synth_new.js`)에 피아노 · 하프 · 팀파니가 없으면 더한다. 피아노는 실제 녹음 샘플이 있으면 그것을 쓰고, 합성이면 해머 · 현 여러 줄의 맥놀이 · 댐퍼 페달 울림까지 넣어 진짜처럼.

## 5. 건드리지 말 것
- `js/` · `css/` · `index.html` · `img/` 는 고치지 않는다. 음악 파일 · `tools/bgm/` · NOTES.md 만.
- 커밋 · 푸시하지 않는다.
- 다른 게임 · 영화 음악의 선율을 따오지 않는다.

## 6. 순서
`bgm_last_oath` 한 곡을 먼저 만들어 보여 준다(변주가 가장 잘 드러나는 곡). 결이 맞으면 → 타이틀 → 나머지 대전 4곡 → 깃발 9곡.
