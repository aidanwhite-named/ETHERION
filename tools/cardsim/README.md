# 카드 대전 시뮬레이터 (tools/cardsim, v0.1)

모든 카드(유닛 384 · 마법 153 · 아이템 72 = 609장)를 단체 기본 덱에 넣어, 게임과 같은 규칙·컴퓨터(js/ 폴더)로 대전시켜 카드 값을 잰다.

## 돌리는 법

```
node tools/cardsim/cardsim.js            # 전체 (약 31만 판. 2코어에서 50분쯤)
node tools/cardsim/cardsim.js --part 1/2 # 반으로 나눠 다른 컴퓨터와 같이 돌릴 때 (2/2는 다른 곳에서)
node tools/cardsim/cardsim.js --groups B1 --games 30   # 한 단체만, 빨리
node tools/cardsim/cardsim.js --cards G2-42,I4-2 --salt again --out tools/cardsim/verify   # 다른 판으로 다시 확인
node tools/cardsim/report.js             # out/ 의 결과를 모두 합쳐 cards.csv · report.md · summary.json
```

`--time 150` 을 붙이면 150초가 지나면 저장하고 멈춘다. 다시 실행하면 이어서 한다.

## 무엇을 재나

1. **기준 승률**: 단체마다 기본 덱으로 상대 8단체와 1,920판.
2. **카드마다 실험**: 그 카드를 기본 덱에 2장 더 넣고(최대 장수까지), 같은 종류에서 레벨이 가장 가까운 카드를 그만큼 뺀다. 이미 최대 장수(실피스의 계약자 4장, 역전 마법 1장)면 반대로 빼고 채운다. 상대 8단체와 480판, 선후공은 번갈아.
3. **대전 값 풀기** (report.js): 바꾼 덱의 승률 변화에는 뺀 카드의 값이 섞인다. 모든 실험을 한꺼번에 놓고 카드 1장의 값을 최소제곱으로 푼다. 레벨이 가까운 카드끼리만 바꿔서 식이 모자란 곳은 "값은 대개 0 근처"라는 약한 가정(폭 τ, 결과에서 고름)으로 메운다.
   - **대전 값 0** = 그 단체·종류의 보통 카드. **+3** = 보통 카드 2장 대신 이 카드 2장을 넣으면 승률 +3%p.
   - 오차는 1표준오차(카드당 약 ±1.7%p). "강함/약함"은 값이 오차의 2배를 넘는 카드.
4. **사용 통계**: 판당 뽑은 장수, 뽑은 것 중 낸 비율·결정화한 비율, 마법이 실제로 발동한 비율, 처음 낸 턴.

## 다른 시뮬레이터와의 관계

- 유닛(코인 카드)·마법·아이템 시뮬레이터는 카드 한 장을 정해진 환경(1:1 결투, 기준 전장, 기준 유닛)에서 따로 잰다. 그 값이 `js/data.js` 에 들어가 있다.
- 이 시뮬레이터는 `js/data.js` 를 읽어 게임 전체(에테르·유지비·결정화·손패·컴퓨터 판단·덱 안의 다른 카드)를 돌린다. 그래서 단독 시뮬레이터에서 카드를 고쳐 `js/data.js` 에 옮기면 여기서 바로 반영된다. 반대 방향(여기 결과를 단독 시뮬레이터가 읽는 것)은 없다.
- 결과는 컴퓨터(보통)의 판단에 기대어 있다. 컴퓨터가 잘 못 쓰는 카드는 약하게 나온다.

| 파일 | 내용 |

| out/result_*.json | 대전 원자료 |
| out/cards.csv | 카드 609장 표 (엑셀로 열기) |
| out/report.md | 요약 보고서 |
| out/summary.json | 정리한 값 전부 |
