# ETHERION 유닛 밸런스 v1.3 — 스탯 가격표 · 음수 방어 제거 · 단체 체력 보정

도구: `tools/rebal13/` (맨 아래 "다시 돌리는 법"). 바꾸기 전 유닛은 `_backup_v1.2/js/data.js`.

## 1. 지금 스탯은 어떤 식이었나
- **레벨 사이: 지수 곡선.** 유지비 0 카드의 기대 공격 + 기대 체력(코인 기대값 포함) ≈ `5.06 × 1.19^(레벨−1)`. 측정값 5.06 → 6.02 → 7.41 → 8.96 → 10.67 → 12.57 → 15.17 → 17.88 (레벨당 ×1.18~1.23). v0.8 `rescale.js`의 `NEW_SUM`.
- **레벨 안: 선형 합, 공격 ≈ 방어 + 체력.** 카드는 1:1 결투 승률로 맞췄는데, 그 결투는 "한 방에 `공 − 방 ≥ 체`면 쓰러짐, 피해는 턴 끝에 회복"이라 방어와 체력이 완전히 같은 값이었다. 그래서 방어 −1을 체력 +1로 사도 같은 값으로 잡혔고, 음수 방어가 139장(+음수 방어 코인 12개) 생겼다.

## 2. 스탯 1점의 실제 값
### 실제 게임 (컴퓨터 대 컴퓨터, 마법·아이템 포함, 단체마다 960판, 같은 시드)
| 모든 유닛 +1 | 승률 변화(9단체 평균) | 체력 1 대비 |
|---|---|---|
| 체력 | +15.9%p | 1.00 |
| 공격 | +19.0%p | **1.19** |
| 방어 | +21.2%p | 1.33 |
| 방어 (지금 방어 0 이하 유닛만) | | 1.18 |
| 방어 (지금 방어 1 이상 유닛만, 차이로 추정) | | ~1.56 |

### 교전만 (3대3·4대4 섬멸전, 마법 없음, 4만 판씩) — 목표 유닛의 지금 방어별, 방어 +1 ÷ 체력 +1
| 지금 방어 | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| 3대3 | 1.09 | 1.11 | 1.42 | 1.60 | 1.53 |
| 4대4 | 1.14 | 1.10 | 1.50 | 1.75 | 1.72 |

### 결론
- "방어 1까지는 체력과 같고 1을 넘으면 더 비싸다"는 **거의 맞고, 문턱은 1이 아니라 0**이다. 0 아래 구간은 체력과 같고(1.0~1.1), 0 → 1부터 이미 1.3~1.5배, 그 위는 점마다 약 1.5배.
- 지금 마법 피해는 방어를 무시하므로 실제 게임 값은 교전만 잰 값보다 10%쯤 낮다.

### v1.3 가격표 (체력 1 = 1점)
```
가격 = 1.2 × 기대 공격 + 방어값(기대 방어) + 기대 체력
방어값(d) = d (d ≤ 0) | 1.3 × d (0 < d ≤ 1) | 1.3 + 1.5 × (d − 1) (d > 1)
코인 하나의 기대값 = 값 × 0.5
```

## 3. 공격이 과하게 높은가
- **점수당으로는 그렇다.** 공격 1이 실제로는 체력 1.2쯤인데 1:1에서 1로 매겨, 공격 비중이 큰 카드가 약 0.2 × 공격만큼 싸게 나와 있었다.
- **전체 크기로는 아니다.** 같은 레벨에서 기대 공격 ≈ 버팀(평균 13턴)이라는 리듬은 유지했다. 피해가 턴 끝에 회복되는 규칙에서 전체 체력을 일괄로 깎으면 모든 공격과 마법 피해(v0.9에서 유닛 체력 기준으로 잰 값)가 함께 세진다.
- 그래서 체력은 **카드마다**, 공격이 큰 카드에서 줄였다. 레벨 평균은 그대로, `(옛 가격 비율 × 기준) − 새 가격`만큼 체력을 더하거나 뺐고, 반올림은 1:1 승률 변화가 작은 쪽으로.

## 4. 음수 방어 제거
- 기본 방어 0 미만 유닛 139장 → **0장**. 방어 −N을 0으로 올리고 체력 N을 뺐다(1:1 승률 그대로).
- 음수 방어 코인 12개는 같은 값의 음수 체력 코인으로. 코인이 어떻게 떠도 방어는 0 아래로 내려가지 않는다.
- 체력이 1 아래로 내려가는 11장(예: 6/−2/2)은 체력 1로 두고 남는 몫만큼 공격을 깎았다(공 1 = 체 1.2).
- 같은 레벨·유지비에 스탯·코인이 똑같아진 카드는 값 차이가 가장 작은 비틀기(공↔체 코인, 공−1·방+1, 공±1·체∓1)로 갈랐다.
- 역행 유닛(돌격) 9장도 같은 원칙으로 바뀜. 교전 승률은 바뀌기 전과 ±3%p 안.

## 5. 특수능력과 가중치 (체력 몇 점과 같은가)
유닛 카드 자체에는 특수능력이 없다(유지비·역행만). 능력은 아이템에 붙고, 일부는 마법이 걸어 준다.

| 능력 | 어디에 | 하는 일 |
|---|---|---|
| 투척 N | 아이템 13 | 장착한 턴의 공격 턴에 상대 유닛 하나에게 방어 무시 피해 N |
| 사격 N | 아이템 9 | 매 공격 턴마다 투척 |
| 관통 | 아이템 4 | 공격할 때 상대 방어를 공격만큼 깎음 |
| 치명 | 아이템 7 | 피해를 줄 때 50% 확률로 두 배 |
| 마력 N | 아이템 11 | 내 공격이 상대 방어를 N까지 무시 |
| 가시 N | 아이템 3, 마법 | 나를 친 유닛에게 피해 N |
| 원거리 | 아이템 1 | 반격을 받지 않음 |
| 보호막 | 아이템 3, 마법 | 턴마다 50%(마법은 확정)로 첫 피해를 막음 |
| 가호 N | 아이템 11 | 한 턴에 처음 받는 피해 −N |
| 고정 | 아이템 6, 마법 | 적힌 값 아래로 스탯이 내려가지 않음 |
| 증폭 N · 치유 N | 아이템 | 공격 마법 피해 +N · 장착할 때 생명 +N (전투 밖) |

- 마력은 2에서 멈춘다(지금 방어가 대부분 0~2). 음수 방어가 사라져 평균 방어가 0.2 → 0.5가 됐으니 마력·관통 값은 조금 오른다.
