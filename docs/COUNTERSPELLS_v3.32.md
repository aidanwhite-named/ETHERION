# 무효 마법 v3.32 — 깃발마다 1장, 모두 9장

> 카드는 `js/counterspells.js`, 등급은 `js/grades.js`가 그 파일의 `COUNTER_GRADES`를 읽는다(모두 **고급**).
> 상대가 방어 턴에 뒷면으로 놓은 마법을 **[무효]**로 하는 **공격 마법**(내 공격 턴에만 낸다). 2레벨은 [무효]만, 3레벨은 [무효] + 효과 하나.
> 기본 덱에는 넣지 않았다. 고급이라 새 모험가의 시작 카드에는 1장씩 들어간다(`js/store.js` `starterCollection`). 상점 재고 80, 덱에 4장까지.
> 시험 `node tools/counter/test.js`, 실험실 `node tools/counter/lab.js 1500`, 잰 값 `tools/counter/out/`.

## 1. [무효] 규칙 (`js/engine.js` `SPELL_OPS.negate`)
- 이 마법이 발동하면 **상대 전장에서 아직 발동하지 않은 마법 중 맨 앞 1장**이 발동하지 않고 부서진다. 원래 주인의 소각장으로 가고(빼앗긴 마법이면 처음 주인), 부서진 카드 기록(조각 정산)에도 남는다.
- **언제 발동하나**: 여느 공격 마법처럼 앞 칸 아군 유닛이 모두 공격한 뒤. 같은 때 발동할 수 있는 마법이 양쪽에 있으면 공격 마법이 먼저다(`runCombatCore` `fire`의 atk → def 순서, 예전부터). 그래서
  - **1번 칸**에 두면 전투가 시작되자마자 상대의 어떤 마법보다도 먼저 — 상대 1번 칸 방어 마법, 칸과 상관없이 먼저 발동하는 opening 마법까지 막는다.
  - **뒤 칸**에 두면 앞 칸 아군 유닛이 싸우는 동안 상대 방어 마법이 먼저 풀릴 수 있다. 이미 발동한 마법은 겨누지 않고 남은 마법 중 맨 앞을 겨눈다.
- 무효로 할 마법이 없으면 [무효]는 헛것("무효 — 대상 없음"). 3레벨의 다른 효과는 그대로 난다.
- 상대 마법은 내 준비가 끝난 뒤에 놓이므로, 낼 때는 상대가 방어 마법을 낼지 알 수 없다 — **읽기 싸움 카드**다. 사람도 보는 것(상대 핸드 장수 · 에테르)으로 어림한다.
- 화면: 무효로 할 마법을 앞면으로 보이고 겨눔 표시(`targeted`) → "무효" 명판 → 부서짐. 새 `fx` 열쇠는 없다(`tgt` · `shown` · `shatter`). 카드 글의 [무효]에는 말풍선(`js/cards.js` `SPELL_KW`, 매뉴얼 능력 사전에도 저절로).

## 3. 잰 값
### 실험실 (`tools/counter/lab.js`, 섬멸전 1,500판 × 판 묶음 둘)
`lab_rare.js`와 같은 섬멸전(내 2~4기 대 상대 2~4기, 유닛 레벨 = 마법 레벨 ±1, 공격 턴 먼저)에서 무효 마법을 내 1번 칸에 넣은 판과 안 넣은 판을 같은 씨앗으로 견줬다.
- **빈판**: 상대가 마법을 내지 않은 판 → 3레벨의 다른 효과만의 값.
- **맞판**: 상대가 방어 · 공용 마법 1장(무작위 깃발, 레벨 L−1 ~ L+2)을 무작위 칸에 낸 판.

| 카드 | 빈판 (4242 / 777) | 맞판 (4242 / 777) |
|---|---|---|
| 2레벨 기존 공격 · 공용 마법 30장 평균 | 9.0 / 9.3 (표준편차 5.3) | 9.3 / 10.9 |
| 봉인 쐐기 · 합선 · 덫 짓밟기 · 주문 끊기 | 0 / 0 | **10.5 / 11.3** |
| 3레벨 기존 공격 · 공용 마법 27장 평균 | 7.3 / 6.8 (표준편차 7.3) | 9.2 / 9.2 |
| 덫 태우기 | 7.3 / 5.7 | 19.5 / 17.9 |
| 이끼 덮기 | 6.2 / 6.4 | 19.9 / 18.5 |
| 씻김의 노래 | 7.6 / 7.2 | 19.1 / 18.4 |
| 피의 침묵 (생명 1 값을 뺀 것) | 10.5 / 9.6 | 22.5 / 20.6 |
| 정화의 빛 | 5.7 / 6.1 | 18.7 / 17.3 |

- 2레벨: 빗나가면 0, 맞으면 같은 레벨 마법 평균만큼. 3레벨: 빗나가도 같은 레벨 마법 평균쯤(z −0.15 ~ +0.45), 맞으면 그 두 배.
- 처음 안에서 고친 것: 이끼 덮기(아군 맨 앞 체력 +2 → 0.4) · 씻김의 노래(해제만 → 0.0) · 정화의 빛(보호막만 → 1.4)의 다른 효과가 너무 약해 지금 꼴로 올렸다.
- 이 실험실의 상대 마법은 1 ~ 5레벨이다. 실제 대전에서 무효가 막는 마법은 더 높다(아래).

### 컴퓨터 대전에서
- 방어 턴에 상대 전장에 마법이 놓이는 비율: **보통 약 8% · 어려움 약 19%**(기본 덱끼리, 평균 4.1 ~ 4.7레벨). 컴퓨터는 방어 마법을 아껴 쓰므로 컴퓨터 상대로는 무효가 자주 맞지 않는다. 사람끼리의 대전(온라인)에서는 이 비율이 판마다 다르다.
- 맞았을 때의 값: 보통끼리 대전에서 그 마법을 뺀 전투와 견주면 공격하는 쪽 판 점수(`evalScore`, 유닛 레벨 단위)가 평균 **+7.5** — 높은 레벨 방어 마법이 많아서다.
- 그래서 대전 값(`tools/cardsim`)으로 재면 2레벨은 낮게 나올 것이다. 등급을 레어가 아닌 고급으로 둔 까닭.

## 4. 컴퓨터 (`js/game.js` `negateHope` · `AI_NEGATE`)
- 미리 굴리기(보통 `spellGain`, 어려움 `hardEval`)는 상대 마법을 모른 채 굴리므로 [무효]의 값이 늘 0이다. 그래서 따로 어림값을 더한다: `AI_NEGATE.v`(0.9) × 상대 핸드 장수(4장이면 다) × 상대 에테르(2 아래면 0.3배) × 내 앞 칸 유닛 수에 따라 1 · 0.55 · 0.3 · 0.15.
- 어려움은 핸드 한 장 값(0.9)을 빼므로 2레벨 무효는 상대 핸드 · 에테르가 넉넉하고 1번 칸에 둘 때만 낸다. 3레벨은 다른 효과의 값이 더해져 더 자주 낸다.
- 무효 마법 덱(깃발마다 4장) 실제 대전 45판(보통 36 · 어려움 9): 오류 없음, 무효 마법 발동 43번 중 실제로 무효 3번.
