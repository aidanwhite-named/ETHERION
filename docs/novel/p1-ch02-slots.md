# 2장 「숨 일곱 번」 — 작가 몫 안내

원고 `p1-ch02.md`에서 ✍ 표시가 작가님이 쓰실 자리입니다. 셋 다 선생님을 **기다리는 일곱 주** 안의 짧은 장면입니다. 앞뒤 사건과 복선에 덜 묶여 있어서 비교적 자유롭게 쓰실 수 있습니다.

- 폰에서 채팅으로 보내 주시면, 제가 원고 자리에 넣고 앞뒤 이음새와 설정 메모를 맞춥니다.
- 막히면 "A 써 줘"처럼 말씀하세요. 그 칸은 제가 채웁니다.
- 셋 가운데 하나만 쓰셔도 됩니다. 하나만 고르신다면 **A**를 권합니다.

## 왜 이렇게 나눴나
- **돌아오는 날부터(초고)**: 복선이 촘촘하게 걸려 있습니다. 꿀 없는 차(37), 고치지 않는 획(01), 무늬(02), 손바닥 메모(26), 환석(05), 이름(41). 번호가 서로 맞물리니 이 부분은 제가 맞춥니다.
- **기다리는 일곱 주(작가 몫)**: 인물의 결을 만드는 시간입니다. 작가님의 목소리와 웃음이 소설의 몸에 들어가기 가장 좋은 자리입니다. 짧아서 폰으로도 쓸 만합니다.

## 셋 모두 지킬 것
- **이름**: 선생님의 이름은 쓰지 않습니다(4-08까지). 이레는 "선생님"이라 부르고, 서술도 "선생님"(이레 시점) 또는 "기록관"으로 씁니다.
- **거짓말**: 이레는 1-09 전까지 거짓말을 하지 않습니다(첫 거짓말이 "중립의 첫 균열"입니다).
- **환석**: 이레는 고리 안에 들어가거나 손을 넣지 않습니다(1-05 ☆). 원고의 환석지기 장면에서 "한 번도 해 보지 않았다"를 깔아 두었습니다.
- **별**: 지붕에서 세는 고리 안의 별은 112개 그대로입니다. 별이 지거나 늘지 않습니다(28 · 29).
- **툭의 옛일**: 포병단이나 북쪽 이야기는 드러내지 않습니다. 움찔하고 말을 돌리는 데까지만(40 → 1-09).
- **말투**: 이레는 툭에게 해요체, 툭은 반말, 선생님은 반말입니다.
- **시점**: 이레의 3인칭 제한 시점. 심리 용어는 본문에 쓰지 않고 보여 주기만 합니다.

## 1장에서 쓴 결
- 짧은 문장, 잦은 줄바꿈. 한 장면에 그림 하나를 또렷하게 둡니다.
- 냄새가 먼저 옵니다. 기록관은 등잔 기름 · 종이 · 라벤더, 툭은 유황 · 꿀빵.
- 감정은 말 대신 손과 물건으로 씁니다("이레는 펜을 씻었다. 오래 씻었다.").
- 장면 끝은 조용한 한 줄로 닫습니다.
- 되풀이하는 말: "문을 닫는 것처럼"(선생님의 말버릇), "이레는 그 말을 하지 않았다", "묻지 않았다".
- 장면 사이는 원고처럼 `　` / `\* \* \*` / `　` 세 줄로 나눕니다.

## A ★ 「혼자 끓인 차」 — 첫째 주 · 600~1,000자 (권함)

| 항목 | 내용 |
|---|---|
| 언제 · 어디 | 선생님이 떠난 이튿날 아침, 기록관 부엌. 원고의 바로 앞 줄이 "이레는 부엌에서 오래 서 있었다."입니다 |
| 주제 | 빈자리는 습관에서 먼저 느껴진다 |
| 이 장면이 하는 일 | 이레가 처음으로 혼자 차를 끓입니다. 뒤에서 돌아온 선생님이 숨 일곱 번 그대로 끓이면서 꿀만 빠뜨릴 때, 독자가 이 장면을 떠올리게 됩니다 |
| 꼭 넣을 것 | 찻잎을 넣고 **숨을 일곱 번** 센다(1장 저녁에 처음 들은 법) · **이 빠진 파란 찻잔** · **꿀 반 숟갈** · 그런데 **맛이 다르다**. 끝내 그 맛을 맞추지 못한다(뒤 장면이 "이레가 마흔아홉 날 동안 한 번도 맞추지 못한 그 박자"로 받습니다) · 꿀단지는 **찬장 맨 앞**에 둔다(뒤에서 선생님 손이 그 위를 지나갑니다) |
| 넣지 말 것 | "눈물이 났다"처럼 우는 것을 말로 쓰기 · 선생님께 차를 끓여 드린 적이 없다는 것을 대사로 설명하기 |
| 이레의 얼굴 | 작은 상처, 그리고 피하기. 울지 않고 맛을 고친다(물을 더 붓거나, 숨을 다시 세거나, 꿀을 더 넣거나) |
| 작가용 메모 | 상실은 큰 사건보다 절차에서 먼저 느껴진다 · 감정 고립(감정을 일로 바꾸기) |
| 감각 재료 | 화덕 불, 주전자 김, 찻잎 냄새, 버릇처럼 꺼낸 찻잔 두 개, 빈 의자 |
| 써도 좋은 그림 | 찻잔을 두 개 꺼냈다가 하나를 도로 넣는다 / 두 번째 잔이 식어 간다(결말 4-14 "차가 식었구나"의 메아리) |
| 첫 문장 후보 | ① "찻잎을 넣고, 숨을 쉬었다." ② "주전자는 선생님이 놓아둔 자리에 그대로 있었다." |
| 넘겨줄 곳 | 다음 장면은 셋째 주 새벽의 광장입니다. 차 장면을 조용히 닫으면 됩니다 |

## B 「꿀빵 셈법」 — 다섯째 주 · 800~1,200자

| 항목 | 내용 |
|---|---|
| 언제 · 어디 | 다섯째 주 어느 오후, 필사실 |
| 주제 | 벗은 말 대신 셈으로 위로한다 |
| 이 장면이 하는 일 | 툭과 이레의 우정. 툭은 사람 마음을 직관으로 읽는 사람이라는 것을 보여 줍니다(2부에서 무너진 카엘에게 닿는 것도 툭입니다) |
| 꼭 넣을 것 | 1장에서 툭이 "석판 깨진 건 갚을게. 꿀빵 셋에서 까."라고 했고, 이레는 "그건 빚이 늘어나는 셈법인데요."라고 받았습니다. 이 셈을 **툭답게** 끝냅니다(새 석판을 들고 온다, 장부의 동그라미를 지워 준다, 일부러 하나 더 그린다, 장을 넘겨 버린다 …) · 툭은 위로한다는 말을 하지 않는다. 농담과 셈으로 한다 |
| 넣지 말 것 | 툭이 이레의 머리 이야기를 꺼내기(선생님이 돌아온 뒤 툭이 처음 알아채는 장면이 원고에 있습니다) · 툭의 옛일 · 이레의 거짓말 |
| 툭의 얼굴 | 웃음으로 버티는 사람(성숙한 방어), 직관. 도화선 앞에서는 빠른 손이 글자 앞에서만 떨린다 |
| 이레의 얼굴 | 받는 데 서툴다. 고맙다는 말 대신 남의 셈법을 고쳐 준다 |
| 감각 재료 | 유황과 꿀빵 냄새, 새 석판의 돌가루, 금 간 옛 석판, 툭의 금니 |
| 써도 좋은 것 | 제 이름의 **둘째 글자**에 도전한다(툭은 4-13에서 제 이름을 끝까지 씁니다 — 이번엔 실패해도 좋습니다) / 꿀빵을 어디서 사 오는지(에필로그에서 툭은 빵집을 엽니다. 그 빵집의 씨앗을 심어도 좋습니다) |
| 첫 문장 후보 | ① "다섯째 주에 툭이 석판을 들고 왔다. 금이 가지 않은 석판이었다." ② "냄새가 먼저 왔다. 유황, 꿀빵, 그리고 처음 맡는 돌가루 냄새." |
| 넘겨줄 곳 | 다음은 C(여섯째 주 지붕)입니다. C를 건너뛰면 마흔아홉째 날 새벽, 가는 비로 이어집니다 |

## C 「빈 지붕」 — 여섯째 주 · 400~700자 (선택)

| 항목 | 내용 |
|---|---|
| 언제 · 어디 | 여섯째 주 밤, 기록관 지붕 |
| 주제 | 혼자 남은 의례 |
| 이 장면이 하는 일 | 둘이 하던 일을 혼자 합니다. 장의 앞쪽(기다림)을 닫고 돌아오는 날로 넘깁니다 |
