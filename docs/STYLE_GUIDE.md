## 0. 기본 원칙

1. **그림은 코드로 그린다.** 지도·카드 틀·아이콘·화면 장식은 모두 SVG, HTML/CSS, Canvas로 직접 그린 것이다. 이미지 생성 AI로 만든 그림이나 외부 이미지 파일은 쓰지 않는다.
2. **예외는 셋: 카드 일러스트, 타이틀 그림, 상단 문장.** 카드 그림 자리에 `img/cards/<카드ID>.png`가 있으면 그 그림을 보여 준다(6장). 타이틀 화면의 키 아트 한 장(`img/title/title_art.jpg`, 2.17)과, 같은 키 아트의 위쪽 띠를 쓰는 상단 문장(`img/ui/etherion_keyart.jpg`, 2.15)도 이미지 생성 AI로 만든 그림이다 타이틀 그림은 전장 배경(불투명도 20%, 2.17)으로도 쓴다. 이 셋 말고는 이미지 생성 AI 그림을 쓰지 않는다.
3. **모든 색은 이름 붙은 값(CSS 변수, 데이터의 color)으로 쓴다.** 새 색을 아무 데나 직접 적지 않는다. 필요하면 아래 표에 먼저 추가한다.
4. **같은 대상은 어디서나 같은 색과 같은 문양.** 단체 B1은 지도에서도 카드에서도 화면에서도 같은 주황빛, 같은 총 문양이다.
5. **두 세계의 톤을 섞지 않는다.**
   - 게임 화면, 카드, 게임 안 지도(`js/kailan.js`): **밤하늘과 금빛 룬** (어두운 테마 하나로 고정)
   - 아티팩트 지도 "카일란 대륙 전도": **양피지 해도** (밝은 기본 + 어두운 모드에서는 "밤의 해도")
   - 지도는 두 벌이다. 지명·좌표(1200×900)는 같고 화풍만 다르다. 5장 참고.

### 2.4 반복해서 쓰는 장식
- **배경**: `body::before`에 위쪽이 보랏빛인 방사 그라데이션(`#1a1630 → #0b0d17 → #07080d`), 그 위에 세 존재(2.10), 그 위 `#bg-canvas`에 깜빡이는 별과 위로 떠오르는 에테르 입자(금·하늘·연보라·주황, `lighter` 합성). 움직임 줄이기 설정이면 멈춘다.
- **금빛 글자**: 큰 제목은 `#fff6d6 → #f0d48c → #b8893a → #f7e1a0` 세로 그라데이션을 글자에 칠하고 금빛 그림자.
- **버튼**: 기본은 어두운 남색 그라데이션 + 금빛 선. 주 버튼은 금(`#e6c47c → #b48a3c`) 바탕에 어두운 글자, 보조 주 버튼은 보라(`#8f6fd6 → #5b3fa0`).
- **보석·구슬**: 둥근 것(레벨, 에테르 구슬, 결정)은 왼쪽 위가 밝은 방사 그라데이션으로 입체감을 준다. 레벨 = 금 구슬 `#fff3c9 → #d6aa52 → #7d5a1c`, 에테르 = 하늘 구슬 `#f2fcff → #6cc9f2 → #1c6a99 → #0a2236`.
- **모서리**: 버튼과 패널은 작게 둥글린다(2~5px). 에테르 계기판처럼 떠 있는 큰 장치만 더 둥글게(14px 안팎).


### 2.12 에테리온 문장 (`js/screens.js` `SIGIL` · `ringSVG`, v3.2)

### 2.14 장면 배경 · 덱 조정실 계기판 (`js/scenes.js` · `css/scenes.css`, v3.4)
- **원칙**: 하늘(별 · 에테르 입자 · 세 존재)은 그대로 두고, 그 아래에 그 화면이 **세계의 어디인지**를 코드로 그린다. 모든 움직임에는 뜻이 있다(장식만을 위한 움직임은 넣지 않는다). 글자와 카드보다 눈에 띄지 않게 장면 불투명도 .78~.9, 그 화면의 판(`.shop-main` · `.ed-pool`)은 바탕 .7~.8로 장면이 조금 비친다. 세 존재 세기는 교역소 .34 · 덱 조정실 .3 · 대기실 0(그리지 않음, v3.5.8). 실루엣 색 `--sil #05060b`.

### 2.8 카드 움직임 (`js/game.js` · `js/feel.js` `FEEL.t`, v1.7)
- 시간 값은 `FEEL.t` 한곳: 고르기 380ms(v2.6) · 자리 옮기기 300 · 핸드 안에서 모이기 420(v2.6 `handMove`) · 밀려나기 340 · 착지 420 · 제자리 복귀 400.

- **착지**: 가속하며 빨려 들어(56%에서 닿음) 가로 1.07 · 세로 .9로 눌렸다가 .97 · 1.035로 튀고 멈춘다. 칸 둘레 금빛 고리(`.suck-ring`, `rgba(246,226,168,.85)` 테두리 + 같은 색 빛)가 1.45배에서 카드 크기로 조여들고, 닿는 순간 안쪽이 `#fff3c9`로 한 번 환해진다.
- 끝에서 크게 넘치는 탄성(1.1 이상)은 손이 한 일(고르기·복귀)에 쓰지 않는다. 묵직하고 부드럽게.
- **드로우**(v1.9): 덱에서 뒷면으로 튀어 올라 카드 높이 .75배 위로 호를 그리며 1.32배까지 커졌다가, 30~62% 구간에서 앞면으로 뒤집히고 제자리에 앉아 한 번 밝게 빛난다(0.64초, 0.15초 간격, 보라·하늘 빛 꼬리). 셔플이면 그 전에 덱이 좌우로 흔들린다.
- **자리 옮기기**(v1.9): 맞바꾸지 않고 밀어 넣는다. 밀리는 카드들이 모두 옮기는 카드 뒤로 지나간다.
- **장착한 유닛**(v1.9): 아이템 카드는 기울이지 않고 카드 높이의 약 3%만큼 똑바로 아래로 비껴 깐다.
- **핸드**(v2.6, `css/hand.css` — 핸드의 자세·곡선·그림자는 모두 이 파일. `js/game.js` `setHov`·`applyHov`·`syncHov`):

### 2.9 마법 연출 · 코인 수치 (`js/spellfx.js` · `css/spellfx.css`, v1.9.5)
- **색**(`css/spellfx.css`의 `:root`): `--coin-up #a6f04a`(코인으로 오른 값, 연두) · `--coin-down #ff4b3e`(내린 값, 빨강) · `--fx-blood #e0344a`(피·대가) · `--fx-shield #9be8ff`(보호막) · `--fx-heal #7fe39c`(회복) · `--fx-spark #ffd27a`(폭발 불티). 그 밖의 효과 색은 단체의 원소색(1.2 `--el`)을 쓴다. 저주의 어둠 고리는 암흑 원소색 `#8b5cf6`.
- **코인 수치**: 캐릭터 그림 위 40% 높이에 Cinzel 900, 카드 폭의 33%(최소 40px), 검은 외곽선 + 같은 색 빛. `+N`은 1.5배로 튀어 올랐다 자리 잡고 위로 떠오른다. `−N`은 위에서 내리꽂혀 좌우로 흔들린 뒤 아래로 가라앉는다. 스탯 아이콘을 앞에 붙이고, 여럿이면 1.02em씩 아래로 쌓는다.
- **코인 창**: 1.5배. 앞면이 서는 순간 코인이 1.2배로 튀고 금빛 고리 조각이 돈다.
- **코인 앞면 = 에테리온 문장** (v3.2, `js/game.js` `COIN_CREST` · `css/spellfx.css` `.cs-crest`, 짜임은 2.12): 금화에 판다. 구슬 테(56알 중 돌 자리는 비움) 사이에 **거인의 돌 일곱**(돋을새김 + 가로 홈), 고리 위 일곱 자리에 원소색 보석(타이틀 고리 `SEATS`와 같은 방위: 북 대지 · 북동 바람 · 남동 화염 · 남 물 · 남서 숲 · 서 금속 · 북서 번개), **동쪽은 빈 홈에 `?`**, 그 양옆 고리는 끊긴 점선. 가운데는 **신의 다섯 꼭짓점 별**(꼭짓점마다 한쪽 밝고 한쪽 그늘, 끝에 공을 달지 않는다 — 보안관 별처럼 보여서), 한가운데 아르케 단추. (v2.9~v3.1의 칠룡환: 나침반 바늘 + 팔각별, 거인·신 없음.) 무늬 색은 금화의 세 색(`#2a1c04` 홈 · `#fff3c9` 턱 · `#8a6220` 가운데 단추)만 쓰고, 색은 보석에만 넣는다. 도는 동안은 양면 모두 `?`(문장 숨김), 앞면으로 선 뒤에만 보인다. 카드 위 작은 금화에는 넣지 않는다.
- **코인 뒷면 = 빈 자리** (v3.0, `js/game.js` `COIN_BACK`): 에테리온 문장을 뒤에서 본 그림. 앞면과 같은 구슬 테와 **거인의 돌 일곱**(v3.2, 잿빛 돋을새김 — 용은 떠나도 몸은 남는다) 안에 **보석이 빠진 일곱 홈**(앞면의 좌우 거울, 빈 방위는 서쪽)과 끊긴 점선 고리, 가운데는 **여덟 번째 자리 = 갈라진 검은 구멍**(점선 테 + 잔금 여섯) 한가운데 **에테르 하늘빛 한 점**(`--ether #8fdcff`, 네 갈래 반짝임 + 흰 심). 무늬는 잿빛 뒷면(`.cs-tails` `#7a7a8a → #2a2a36`) 위에 검정 반투명 홈 + `#b9b9c8` 턱으로 판다. 색은 가운데 빛뿐(앞면의 보석 일곱과 대비). 앞면에 숫자를 새기지 않는다(코인 값은 +2·−1도 있어 "+1짜리"로 읽힌다). 공·방·체가 함께 붙은 코인의 "뒷면" 글자는 쓰지 않는다.
- **마법이 뒤집힐 때**: 카드 둘레(카드 큰 변 × 1.55 × 1.12)에 원소색 룬 고리(점선 바깥 원 · 가는 원 · 끊긴 안쪽 원 · 열두 점과 마름모). screen 합성, 돌며 커졌다 사라진다. 원소 입자 14개가 카드로 빨려 든다.
- **원소별 발사체** (고르는 곳: `js/spellfx.js`의 `KIND_OF_EL`(원소 → 모양)과 `THEME_BY_NAME`(이름 속 말 → 모양)): 포탄(쇳빛 공 + 불붙은 심지, 연기 꼬리) · 리벳(은빛 막대) · 번개(하늘에서 갈지자, 흰 심 + 원소색 번짐) · 바위(울퉁불퉁 갈색) · 갈라짐(대상 발밑 검은 금 + 원소색 번짐) · 가시(아래에서 솟는 초록 가시 다섯) · 화살(왼쪽 위에서 여섯 대) · 물덩이 · 물마루 · 어둠 덩이(검은 속 + 보라 테) · 붉은 초승달 · 빛기둥(위에서 아래로) · 빛의 창 · 바람 칼날 둘 · 유성(불꼬리) · 불덩이.
- **맞는 순간**: 원소색 빛 터짐 + 고리 + 그 원소의 입자, 대상 카드가 흔들리고 한 번 밝아진다. 숫자는 이때 뜬다.
- **강화·약화**: 강화는 아래에서 위로 원소색 기둥 + 바닥 타원 고리 + 떠오르는 입자(화염 불티 · 금속 네모 · 번개·빛 마름모 · 대지 네모 · 숲 잎 · 물 방울 · 암흑 연기 · 바람 줄). 약화는 위에서 내려앉는 어둠 + 좁아지는 어둠 고리 + 가라앉는 보라 연기, 카드가 잠깐 어두워진다.
- 움직임 줄이기 설정이면 그리지 않는다.

- **판**: 패널은 위 끝 밝은 선 + 아래로 쌓인 5px 금빛 그림자(`--slab-edge`) + 긴 그림자. 바탕 불투명도 .8~.88(세 존재가 비치되 글자가 먼저). 양옆 패널 3.2도, 마우스 따라 1.8도(`SIDE_DEG` `FOLLOW_DEG`). 긴 패널은 마우스 기울기를 22%만.
- **카드**: 마우스 밑 카드는 13도까지 기울고 26px 떠오르며 빛(`.d3-glare`)이 따라온다. 두께 그림자는 `:where()`로 낮은 우선순위라 고름·공격 상태의 빛이 늘 이긴다.

- **기울이지 않는 화면**(v3.8.2 교역소 · v3.8.3 대기실 · 덱 조정실): `.shop-tree` · `.shop-main` · `.decks` · `.chat` · `.deck-view` · `.ed-deck` · `.ed-pool` · `.ed-preview`는 마우스를 따라 기울지 않고 판 등장 연출(`d3Rise`)도 없다. 카드 등장 연출(`d3Deal`)은 지웠다. 목록을 자주 다시 그리는 화면이라 매번 카드 칸 전체가 기울거나 밀려 내려가 보였다. 마우스 밑 카드 한 장의 기울기와 빛은 그대로. 판이 기우는 화면은 관리자 보관소 · 원정 · 입장 관문만 남는다. 목록을 자주 다시 그리는 새 화면은 기울이지 않는다.
- **기울지 않는 카드 · 상자**(v3.9.5): 대기실 덱 보기의 카드(`.deck-view .card`)는 마우스 밑에서도 기울지 않는다(올리면 3px 떠오르기만). 덱 보관함 상자는 올리면 앞으로 나오기만 하고 눕지 않는다(`rotateX` 없음).
- 폭 900px 이하: 기울이지 않는다. 움직임 줄이기: 마우스 반응·등장 연출 없음, 세 존재는 멈춘 한 장.

### 3.1 틀
- 비율 **5:7**. 크기는 `--cw`로 정하고 안의 모든 크기는 `em`(= 카드 너비의 10%)으로 맞춰 어떤 크기에서도 같은 모습이 된다. 기본 너비 sm 96px, md 138px, lg 220px.
- 위에서 아래로: **머리**(레벨 금 구슬 + 이름 + 오른쪽 위 배지) → **그림 자리**(왼쪽에 레벨 아이콘과 공·방·체 세로 열) → **설명 글**.
- **틀 색**: 진영색(`--fc`)에서 짙은 바탕(`--fc-deep`), 거의 검정(`#0e0d13`)으로 비스듬히 내려가는 그라데이션. 테두리는 진영색 75%. 모서리 `.55em`.
  - 마법 카드: 진영색을 18%만 섞어 더 어둡게.
  - 아이템: 바랜 금빛 `#3a3222 → #1c1912 → #0e0d0a`, 테두리 `#b99b5a`.
- **아이템을 장착한 유닛**: 아이템 카드 틀(위 색)이 아래에 비껴 깔린다(오른쪽 .2em · 아래 .26em, 2.2도). 유닛 틀 아래에는 두 겹 테두리 그림자(`#8a7342`, `#3a2f1c`)로 두께를 준다.
- **전설 카드** (8레벨이고 유지비 2 이상): 틀 위로 빛 띠가 천천히 지나가는 포일 효과.
- **카드 뒷면**: 짙은 보라 방사 그라데이션(`#2a2140 → #110e1b`) + 금빛 테두리 + 동심원 고리와 빗금. 전장에 뒷면으로 놓인 마법은 보라 빗금(`#7a5fd0`).

### 3.2 그림 자리
- 바탕: 가운데가 원소색으로 빛나고 가장자리로 갈수록 거의 검정이 되는 방사 그라데이션. 그 위로 아주 옅은 사선 줄무늬.
- 일러스트가 없으면 가운데에 **단체 문양**(4장)을 원소색 빛과 함께 그린다.
- 일러스트가 있으면 그림이 자리를 꽉 채우고(잘라서 맞춤), 위아래에 옅은 어두운 그라데이션이 덮여 글자와 배지가 읽히게 한다.

### 3.3 배지와 숫자
- 오른쪽 위 **정사각형 = 마법 종류** (칼·방패). **동그라미 = 클래스** (v2.7, 게임 v2.3): 유닛은 자기 클래스 하나, 아이템은 장착할 수 있는 클래스(여럿이면 여럿, 모두면 빈 동그라미 하나). 아이템의 보석 배지는 쓰지 않는다. 아이콘은 `js/view.js`의 `CLASS_ICON`(viewBox 24): 무도 = 쥔 주먹, 무장 = 엇갈린 두 검(폼멜 동그라미), 마도 = 네 갈래 별 + 작은 별, 기도 = 모은 두 손 + 위 빛살 셋, 공용 = 빈 동그라미(안쪽 가는 고리). 테두리·빛은 1.3 표의 클래스 색(`.clc-*`).
- **이름 옆 클래스 꼬리표**: `이름: [무도]` · `이름: [무장, 기도 전용]` · `이름: [공용]`. 금색(`--gold`), 이름보다 작게. 작은 카드에서도 보이고, 좁으면 이름과 함께 줄을 넘긴다(3줄까지).
- **고정**: 고정된 스탯 숫자 옆에 금빛 자물쇠(`LOCK_SVG`, `#ffd36b` + 빛), 숫자도 금빛(`#ffe08a`). 아이템에서 붙는 값이 없는 스탯은 흐린 `+0`(점 "·"은 쓰지 않는다).
- **레벨 말풍선**(`data-tip-kw`): 줄마다 같은 크기, 줄 앞 `[레벨 N]`·`[유지비 M]`만 금빛 굵게, 줄 사이 6px.
- 공·방·체는 **그림 왼쪽 세로 열**(레벨 아이콘 아래), 위에서부터 공 · 방 · 체.
  - 작은 카드(노멀·큰·컴팩트): 칸 테두리도 아이콘도 없이 **숫자만**. 숫자 색으로 살짝 구분(공 `#ffd2bf` · 방 `#d3e6ff` · 체 `#ffc9d1`).
  - 원본 카드: 아이콘 + 큰 숫자. 아이콘은 `js/view.js`의 `STAT_SVG`: 공격 = 곧은 칼(`#ff9a7a`), 방어 = 가운데 무늬 없이 오른쪽 반을 옅게 음영 넣은 방패(`#8fc0ff`), 체력 = 핏방울(`#ff6f82`). 하트·십자 방패(⛨ ♥ 글자)는 카드에 쓰지 않는다.
- 레벨 아이콘은 작은 카드도 원본처럼 두 줄로 촘촘하게(열 폭 .8em ≈ 칸 높이). 아이템도 같은 왼쪽 열에 붙는 값(`+3`)·코인, 고정 아이템은 금색 숫자.
- 카드에는 균형 작업용 값(시뮬레이터 승률·환산 레벨·이전 수치·이전 문구)을 보이지 않는다.
- 코인은 숫자 바로 옆에 **앞면 값 글자 + 코인 수만큼 겹친 빈 금화**. 앞면 값이 1이면 `+`(또는 `−`)만, 2 이상이면 `+2`처럼 부호 뒤에 값을 쓴다. 금화 안에는 숫자를 넣지 않는다(v2.3 · 게임 v1.9.1: `②`가 "코인 2개"로 읽혀서). 값이 다른 코인은 따로 묶는다: `+2● +●`. 음수 코인도 같은 금화이고 앞의 붉은 `−`로만 구분한다(v1.4.6). 한 자리 숫자는 가장 넓은 숫자 폭(.7em)에 맞춰 코인 줄을 맞추고, 두 자리는 그대로 길어진다. 금화 색은 바랜 금(`#d9c07a → #a87d2c → #5a3f12`), 너무 밝게 빛나지 않게.
- 원정 경로의 용 아이콘은 `js/expedition.js`의 `dragonSVG` (단색 실루엣, 원소색), 빈 자리는 점선 원 안의 `?`.

## 4. 문양(SVG 아이콘) 그리는 규칙

카드 그림 자리의 임시 문양, 배지 아이콘, 레벨 아이콘을 새로 만들 때.

- **단색 실루엣.** `viewBox="0 0 64 64"`, `fill="currentColor"`. 색은 바깥에서 정한다(원소색).
- **안쪽 선은 검정 반투명**으로 판다: `stroke="#000" stroke-opacity=".35~.45"`, 굵기 2~3. 하이라이트는 흰색 반투명 원 하나 정도.
- 선으로 그리는 문양(폭풍·활·룬)은 `stroke-width` 4~5, `stroke-linecap="round"`.
- 디테일은 적게. 96px 카드에서도 무엇인지 알아볼 수 있어야 한다.
- **마법 카드**: 단체 문양을 56%로 줄여 가운데 두고, 둘레에 **점선 룬 고리 두 겹**(r 28 점선, r 23 실선, 반투명)을 두른다.

- 위치: 게임 폴더(D:\ETHERION)의 `img/cards/`
- 이름: **카드 ID 그대로** + `.png`. 예: `B1-01.png`. 카드 ID는 `js/data.js`의 `id` 값이다.
  - 유닛 `B1-01`처럼 단체-번호 / 진영 마법 `MB-01`·`MG-`·`MA-` / 클래스 마법 `MC-` / 단체 마법 `SB1-01`처럼 S+단체 / 역전 마법 `RB1-1` / 아이템 `IB1-1`, `I2-1`, `C3-1` 등.
  - 정확한 ID는 반드시 `js/data.js`에서 확인한다. 게임 안 원본 카드 창에도 "그림 파일: img/cards/<ID>.png"가 적혀 있다.
- 형식: PNG, **세로 4:5** 권장 (예 800×1000. `img/cards/README.txt`와 같은 기준). 게임을 새로 고치면 바로 보인다(코드 수정 필요 없음).

### 6.2 구도
- 그림 자리는 카드마다 비율이 조금씩 달라 **가장자리가 잘린다.** 주인공은 **가운데 70% 안에** 둔다.
- 위쪽에 이름·배지, 아래쪽에 숫자가 겹치므로 위아래 끝에는 중요한 것을 두지 않는다.
- 한 장에 주인공 하나. 유닛은 상반신~전신, 마법은 효과가 터지는 순간, 아이템은 물건 하나를 가운데에.

### 6.3 그림체
- **어두운 판타지 카드 일러스트.** 회화풍 디지털 페인팅, 극적인 조명.
- **배경은 어둡게**(밤하늘 남색 `#07080d` 계열), 주인공 뒤로 **원소색 빛**(1.2 표)이 번진다. 카드 틀의 그림 자리가 원래 그렇게 생겼기 때문에, 일러스트도 같은 빛 구조를 따르면 문양 카드와 섞여도 어색하지 않다.
- 진영 분위기를 지킨다: 아다만트 = 구리·증기·기계, 푸른숲 = 자연·나무·물, 비술 = 빛과 어둠·별·마법진.
- 아이템은 바랜 금빛 조명, 물건이 은은히 빛나게.

### 6.4 하지 말 것
- 그림 안에 **글자, 숫자, 서명, 워터마크, 카드 틀, 테두리, UI**를 넣지 않는다 (게임이 직접 그린다).
- 밝은 흰 배경, 만화풍 굵은 외곽선, 사진 같은 실사, 귀여운 SD 그림체.
- 실존 인물, 다른 게임·영화의 캐릭터와 닮은 모습.

### 6.5 프롬프트 틀
아래 틀에 카드 정보를 채운다. 대상 설명은 카드 이름, 단체(1.2 표의 "누가, 어떤 모습"), 아이템이면 `js/data.js`의 `desc`, 세계관 문서의 장소·인물 설명에서 가져온다.

## 7. 새 그림을 만들 때 확인할 것

- [ ] 색은 이 문서의 표나 CSS 변수에서 가져왔다
- [ ] 같은 단체·진영은 다른 곳과 같은 색, 같은 문양이다
- [ ] 게임 화면은 어두운 테마, 지도는 양피지 해도 (섞지 않았다)
- [ ] 한글 본문은 명조 계열 글꼴이다
- [ ] 작은 크기(96px 카드, 좁은 휴대폰 화면)에서도 알아볼 수 있다
- [ ] 지도의 난수 기호는 고정 시드로 그렸다
- [ ] 일러스트에 글자·틀이 없고, 주인공이 가운데에 있다
- [ ] 새 규칙을 정했다면 이 문서에 적고 버전을 올렸다
