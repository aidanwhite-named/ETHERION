# 유니크 — 강화 특수능력 (v3.31)

유니크는 이제 **강화 특수능력(`gift.u`)을 가진 유닛**이다. 강화 특수능력은 마법 · 아이템 · 다른 카드에 없는 능력이고, 한 능력은 한 카드에만 있다. 깃발마다 2장, 모두 18장, **모두 6레벨 · 유지비 1**.

- 카드 · 능력 글: `js/uniques.js` (`UNIQUE_ABIL` 이름 · 뜻, `UNIQUE_UNITS` 카드, `UNIQUE_TOKENS` 소환물). 카드의 [이름] 칩과 뜻은 `js/cards.js`가 `UNIQUE_ABIL`에서 읽는다.
- 규칙: `js/engine.js` 맨 아래 "v3.31 강화 특수능력". 턴이 지나도 남는 값은 유닛의 `t.keep`(resetTurn이 지우지 않음). 핸드 · 덱으로 가는 카드는 전투 복제본의 `p.gain` · `p.deckTop`에 모았다가 `js/game.js` `runCombat`이 넣는다. 난수는 엔진의 `flip()`만.
- 덱: 같은 유니크 1장, **유니크는 덱에 2종까지**(`UNIQUE_DECK_MAX`, `uniqueBlock` — 덱 조정실 · `Store.validateDeck` · 상점의 덱 넣기 · 컴퓨터 맞춤 덱 · 원정).
- 스탯: 새 기준 6레벨 예산 (4 + 2 × 6) × 1.20 + 유지비 1.5 + 깃발 보정 ≈ 20.7점(레어와 에픽 사이). 세기의 나머지는 능력.
- 시험: `node tools/uniques/test31.js` (능력마다 장면 시험 + 유니크 2장 덱으로 실제 대전 90판).
- 카드 ID `UN-??-7`은 처음 7레벨로 만들 때 붙인 이름이다. 그림 작업(`tools/art/`)이 이미 이 ID를 쓰고 있어 그대로 두었다 — 레벨은 6.

## 설계 문서에서 바뀐 것
- **잿불 고블린 "포격 표적" → "불씨 전염"**: 칸이 매 턴 왼쪽으로 당겨져 칸에 남는 표적이 성립하지 않는다. 지금 에픽 마법의 "유폭"과도 겹치지 않게.
- **성광 천족 "빛의 결계" → "날개 그늘"**: 이 유닛이 서 있으면 직접 공격(생명 피해)이 일어나지 않아 발동할 수 없었다. "동료 대신 맞는 날개"(세계관 6장)로.
- 다시 자라는 뿌리의 "불에 쓰러지면 되살아나지 않음"은 뺐다(피해를 준 쪽의 원소를 엔진이 따로 기록하지 않음).
- "다음 턴 시작에" 일어나는 효과는 모두 "다음 턴 **전투가 시작될 때**"로 — 전투 엔진 안에서 일어나야 연출 · 기록 · 컴퓨터의 수 읽기가 함께 맞는다. 칸 번호 대신 빈 칸(맨 뒤)에.
