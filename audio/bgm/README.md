# ETHERION 배경음 (BGM)

게임에서는 `js/bgm.js`가 튼다. 음량은 설정의 **배경음: 끄기 / 작게 / 보통**(효과음과 따로). 모든 화면 오른쪽 아래의 **소리 단추 둘**로 배경음(♪, M 키)과 효과음(스피커, N 키)을 따로 끄고 켠다.

## 편성 원칙 (v3.1.3~, 웅장한 판)
- 주선율 **바이올린 · 첼로**, 바탕 **피아노**(페달 아르페지오) + **하프**.
- **화음을 쌓는다**: 선율 아래 3도 · 6도 둘째 성부(비올라 · 첼로), 현악 합주 5~6성부(+ 높은 바이올린 3성부), 호른 3~4성부 · 트롬본 · 튜바, 가사 없는 합창(아~), 콘트라베이스 + 첼로 저음. B부분과 마지막 A는 바이올린 · 현 합주 · 호른(한 옥타브 아래)이 선율을 함께 노래한다.
- 반짝임: **오르골 · 첼레스타**가 마디 끝에 화음을 내리긋고, 노움 · 마족 곡은 **하프시코드**가 가볍게 받친다. 부드러운 **팀파니**가 큰 부분의 첫 박과 끝의 작은 롤.
- 쓰지 않는 소리: 마림바 · 실로폰 · 글로켄슈필 · 피치카토 · 기타 · 종 · 북 같은 탕탕 튀는 소리. 가사 없음.
- 모양(대부분): 피아노 · 하프 서주 → A 바이올린(+3도) → A 첼로(+3도, 바이올린 대선율, 호른 들어옴) → B 오케스트라 전체 → A 다시 크게 → 피아노 · 하프 · 현 마무리 → 처음으로 이음새 없이.

## 만든 방법
`tools/bgm/lyric.py`에 악보(선율 · 화성 진행)가 있고, 대선율과 현악 화음 연결은 자동(가장 적게 움직이는 보이싱, 선율과 반음으로 부딪히지 않는 3도 · 7도 대선율)이다. GM 사운드폰트 TimGM6mb(Tim Brechbill, GPL-2)의 악기 샘플로 렌더한다(`sf2.py` 읽기, `mix.py` 잔향 · 루프 접기, `kit.py` 마디 · 반주 틀 · 화음 검사).
편곡은 `tools/bgm/grand.py`(선율 화음 · 다성부 현 · 금관 · 합창 · 하프 · 오르골/첼레스타 · 팀파니). 다시 만들기: `python3 grand.py title flag_B1 …` (인자 없으면 모두, numpy · scipy 필요, 결과 wav → ffmpeg로 `.ogg` · `.mp3`). `python3 lyric.py`는 바로 앞 판(얇은 편성), `pieces.py`는 첫 판. 멜로디와 화성은 모두 새로 쓴 것이다.
