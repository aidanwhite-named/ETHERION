# ETHERION

유닛·마법·아이템 시뮬레이터로 수치를 맞춘 카드로 싸우는 **브라우저 카드 대전 게임** 프로토타입입니다.
설치할 것 없이 브라우저에서 바로 돌아갑니다.

- **지금 버전**: v1.9.5 (마법 연출과 소리 · 코인 "차창" · 코인 창 1.5배 · 코인 수치 +N/−N)
- **버전마다 바뀐 것**: [`docs/CHANGELOG.md`](docs/CHANGELOG.md)

## 실행

- **`ETHERION 실행.bat`을 더블클릭**하면 기본 브라우저에서 열립니다. `index.html`을 직접 열어도 됩니다.
- 영문 글꼴 Cinzel·Cinzel Decorative는 `fonts/`에 있어 인터넷 없이도 보입니다(SIL Open Font License). 한글 글꼴 후보(함렛·송명·고운바탕·본명조)와 타이틀 글꼴은 Google Fonts에서 받아오므로, 인터넷이 없으면 기기 바탕체로 보입니다.

## 계정

- **관리자**: 이름 `admin`, 암호 `etherion` — 모든 단체 덱과 모든 카드를 보유. 관리자 보관소에서 단체별 도감과 모험가 관리.
- **새 모험가**: 진영마다 깃발 하나를 골라 시작합니다(v1.4.4).
- 저장은 이 브라우저의 localStorage(키 `etherion.v3`). 서버는 아직 없습니다.
- 로그인 없이 모든 카드를 쓰는 시험 모드는 `js/store.js`의 `OPEN_PLAY`(지금 `false`).

## 게임 한눈에

- **세 진영 · 아홉 단체**. 덱은 한 단체의 카드로만 40장(같은 카드 4장까지).

  | 진영 | 단체 |
  |---|---|
  | 황동 연합 | 화약 포병단 · 강철 골렘 공방 · 뇌전 학술원 |
  | 녹음의 맹약 | 바위송곳니 부족 · 고목 수호회 · 샘물 무녀단 |
  | 비전 성회 | 심연 계약단 · 성광 기사단 · 폭풍탑 마도회 |

- **카드**: 유닛 · 마법 · 아이템. 등급은 일반 · 고급 · 레어 · 에픽 · 유니크 · 스페셜(`js/grades.js`, `docs/GRADES.md`).
- **대전**: 컴퓨터 대전, **칠룡의 고리 원정**(여섯 번 싸우며 카드를 모음), 상점(교역소), 크로네아의 수레바퀴, 전장의 작은 게임(파친코 · 결정 키우기), 날씨.
- **숨겨진 기록**: 카일란 대륙 전도 — 여는 법은 `docs/CHANGELOG.md`의 v0.9.2.

### 기본 규칙

- 생명·덱 40, 시작 핸드 6장(생명 34). 매 턴 두 플레이어 모두 6장까지 보충하고, 뽑은 장수만큼(최소 1) 생명이 줄어듭니다. 시작할 때 한 번 멀리건.
- 턴 순서: 공격 준비 → 방어 준비 → 전투 → 정리. 공격 턴과 방어 턴이 한 번씩 지나면 1 라운드.
- **에테르** = 위대한 정수 1 + 결정 수. 결정화는 턴마다 1장씩 쌓이는 한도 안에서 합니다(3턴 쉬면 한 번에 3장). 결정 최대 9. **Lv N 카드의 비용은 에테르 N.** 남은 에테르는 넘어가지 않습니다.
- **유지비**: 레벨 아이콘 중 빈 칸의 수. 살아남은 카드는 다음 턴부터 유지비만큼 에테르가 빠지고, 모자라면 유지비가 큰 유닛부터 소각.
- **전투**: 공격 유닛이 1번 칸(선두)부터 상대 대기열 맨 앞과 싸움. 맞붙을 때마다 코인을 던지고, 뒷면 코인은 에테르 1로 한 번 다시 던질 수 있음. 막을 유닛이 없으면 레벨만큼 생명 피해, 맞은 쪽은 다음 턴 에테르 +1.
- **마법**은 뒷면으로 칸을 차지했다가 정해진 때 발동. **아이템**은 준비 단계에 같은 단체 유닛 하나에 장착. 소환할 빈 칸이 없으면 소환된 카드는 부서집니다(v1.5).
- 생명 0 또는 덱 0이면 패배. 양쪽 동시면 다음 턴에 공격하는 쪽이 패배.

규칙 근거와 자세한 수치는 `js/game.js`·`js/engine.js` 머리 주석과 변경 기록에 있습니다.
